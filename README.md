# Vendor Radar

**We search everywhere. You just pick where to sell.**

Vendor Radar is a Tampa Bay-first opportunity intelligence service for vendors. It finds, verifies, scores, and organizes current vendor opportunities so vendors spend less time searching fragmented event sites and more time deciding where to sell.

## Public v1

- Free Radar: 3–5 strong current opportunities with deadlines, fees when available, official source links, verification dates, and a Radar score.
- Founding Pro: planned at $9/month for the first 20 paying customers, with personalized Apply Now matches, closing-soon alerts, newly opened opportunities, recurring-market watch lists, and preference filtering.
- Launch market: Tampa Bay.

This repository contains only public-safe site assets and public opportunity data. Private customer, entitlement, and internal research data live elsewhere and are not published here.
